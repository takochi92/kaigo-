# かいごナビ：公開・紹介前の基礎チェック

## この変更で整備したもの

- 問い合わせ・訂正の案内：contact.html
- 配布条件と既存PDFチラシの公開：share.html / assets/handouts/
- 出典、取得日と情報の時点、編集・訂正、広告の方針：sources.html
- 全HTMLのcanonical、JavaScriptなしでも使える基本ナビゲーション
- 404案内、キーボード操作、文字サイズ拡大時の表示確認
- 自動公開前の回帰テスト、リンク・スクリプト・サイトマップ検査、ブラウザ表示検査
- テスト・開発用ファイルを公開成果物から除外
- ローカル保存、外部フォーム・地図の説明をプライバシーポリシーに追加

## 所有者の確認が必要なこと

- [ ] 運営者として公表する名前・活動名、資格、プロフィールを確定。実名・勤務先・資格を推測して追加しない。
- [ ] Googleフォームをログアウト状態で開き、実際にテスト送信し、管理者が受信できることを確認。
- [ ] Search ConsoleでURLプレフィックス https://takochi92.github.io/kaigo-/ の所有権確認、sitemap.xml送信。
- [ ] トップ・読みもの・主要な地域ページのURL検査。サイトマップ送信だけでは検索掲載は保証されない。
- [ ] GA4測定ID G-Z1JQW02KGJ が所有者のプロパティか確認し、リアルタイムで受信確認。
- [ ] GA4の拡張計測（サイト内検索・履歴変更・外部リンク・ファイルダウンロード）に、自由入力の検索語や施設名・相談者情報が含まれないか確認。
- [ ] 既存チラシのInstagram @kaigonavi が実際の所有・運用アカウントか確認。
- [ ] 公開チラシを実際に印刷しQRコードを読み取る（広島市版は広島市の地域ページへ）。
- [ ] スマホ実機で、本文・表・メニュー・検索・文字拡大・PDFの開き方を確認。
- [ ] 全医療・制度記事の根拠と改定情報を個別に再確認。自動テストは内容の医学的・制度的正確性を保証しない。

## 定期運用

- 週1回：公開状態、フォーム受信、検索結果、スマホ表示、Search Consoleのエラーを確認。
- 月1回：データ自動更新のActions結果と取得日を確認。異常時は前回の公開内容を維持し原因調査。
- 制度改定時：影響する記事・用語・計算・チラシを一緒に更新。確認日と根拠を記録。
- 訂正依頼時：対象URL・根拠・修正内容を記録し、内容を照合して対応。
- 紹介活動の前：運営者情報、配布資料、対象窓口の受付方針を確認。

## 確認コマンド

```sh
npm test
npm run build
npm run check
npm install --no-save --package-lock=false playwright@1.62.1
npx playwright install --with-deps chromium
node scripts/check-browser.mjs
```

全国データを再取得せず試す場合、ビルドに --csv-dir と --med-dir で手元のデータを渡す。サンプルデータでの確認は全国データの内容確認とは区別する。
