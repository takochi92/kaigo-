📱 スマホのウィジェットにする

iPhone：本物のウィジェット無料アプリ「Scriptable」を入れ、scriptable-widget.js の中身を新しいスクリプトに貼り付け → ホーム画面を長押し → ＋ → Scriptable のウィジェットを置き、そのスクリプトを選びます。
このページを見るには自分用なのでサイトには公開していません。パソコンで npm run claude を実行して http://localhost:8001 を開くか、Claude に「作業ログを見せて」と頼んでください。
毎日の通知毎朝8時ごろ、前日の作業が GitHub の Issue で届きます（GitHub アプリでプッシュ通知）。このページを開いたときも、前回から増えた作業をお知らせします。
